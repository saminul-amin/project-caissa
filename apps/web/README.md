# Caissa Web

React, TypeScript, Vite, React Router, and Tailwind CSS v4 foundation for the Caissa browser application.

The current app contains only an accessible shell and explicit placeholder routes. It has no chessboard, chess rules, persistence, global state, Stockfish, Maia client, analytics, or production UI.

## Commands

From the repository root:

```text
pnpm --filter @caissa/web dev
pnpm --filter @caissa/web typecheck
pnpm --filter @caissa/web build
```
